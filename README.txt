INTERAKTIV 3D-MODELL AV VARDAGSRUM

Enklaste sättet att köra:
1. Installera Visual Studio Code: https://code.visualstudio.com/
2. Packa upp rum_3d_projekt.zip.
3. Öppna den uppackade mappen i Visual Studio Code.
4. Öppna Extensions och installera tillägget Live Server.
5. Högerklicka på index.html och välj Open with Live Server.
6. Webbläsaren öppnas. Internet behövs för att hämta Three.js från CDN.

Kontroller:
- Dra med vänster musknapp: rotera runt rummet.
- Scrolla eller nyp: zooma.
- Högerklicka och dra: flytta vyn.
- Knapparna ger startvy, vy ovanifrån, vy från soffan och visa/dölj väggar.

Mått: 5,0 × 4,0 × 2,7 meter. Fönsterplaceringen är uppskattad utifrån referensbilden. Dörren är preliminärt placerad på högra väggen. Möbelmåtten är uppskattade.
